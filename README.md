# Commando Museum

Website of the Commando Museum (Musée des Commandos) in Flawinne, Namur: the history of the Belgian
Commandos since 1942. Sister site of the Pegasus Museum, built on the same code base.

Built with Next.js 16 (App Router), Tailwind CSS 4 and Prismic (Slice Machine).

## Getting started

```bash
npm install
npm run dev            # http://localhost:3000
npm run slicemachine   # http://localhost:9999 — edit slices and content types
```

## Content

All content lives in the Prismic repository **commando-museum**.

| Type       | Route                       | Notes                                    |
| ---------- | --------------------------- | ---------------------------------------- |
| `settings` | –                           | Navigation, announcement bar, footer     |
| `page`     | `/` (uid `home`), `/:uid`   | Built from slices                        |
| `news`     | `/news/:uid`                | Optional; listed by the News list slice  |

Pages are composed from the slices in `src/slices` (hero, timeline, artifact spotlight, visit info,
FAQ, portrait grid, library catalogue, …).

Until the repository has any published document, the site renders the bundled seed content in
`src/seed`. As soon as something is published in Prismic, Prismic becomes the only source.

### Pushing seed content to Prismic

```bash
PRISMIC_WRITE_TOKEN=... npm run seed:prismic -- --dry-run          # show the plan
PRISMIC_WRITE_TOKEN=... npm run seed:prismic                       # create missing documents
PRISMIC_WRITE_TOKEN=... npm run seed:prismic -- --update=visit,history   # also overwrite these
```

New and updated documents land in the **Migration release**; publish it in Prismic to make them
live. Publish before running the script again, because documents still in the release are not
visible to it. Existing documents that were edited in Prismic are never overwritten unless
`--force` is passed. Images and PDFs already in the media library are reused.

To preview seed content locally without touching Prismic: `PRISMIC_USE_SEED=true npm run dev`.
The seed images and documents in `public/seed/` are not in git (they are only needed for the import
and that preview); the live site serves every image and PDF from Prismic.

The seed is split by section: `index.ts` (home, museum, team, documentation centre, virtual tour,
visit, shop, membership, magazine, media, links), `history.ts`, `units.ts` and `collection.ts`.

### Library catalogue

The library catalogue on the documentation centre page is not stored in Prismic (it has about
2,000 rows). It lives in `src/data/library.json` as `[title, author, publisher, year, shelf]` rows.
To update it, export the museum's spreadsheet to that format and redeploy.

### Languages

The site is in French (`/fr`, default) and English (`/en`, the Prismic master locale). Visitors
arriving on `/` are sent to the language of their browser. Page slugs are translated
(`/fr/visite`, `/en/visit`). Locales are configured in `src/i18n.ts`.

Seed translations are dictionaries (English → translation) in `src/seed/i18n/<locale>/`, with
translated slugs and language versions of PDFs in `src/seed/i18n/uids/`. After changing English
seed copy, list untranslated strings with `npx tsx scripts/i18n-extract.ts fr-be`.

A Dutch translation is ready (`src/seed/i18n/nl-be/`) but not enabled, because the Prismic plan
allows two locales. To enable it: add `nl-be` in Prismic, uncomment it in `src/i18n.ts`, add it to
`enabled` in `src/seed/translations.ts`, and run `npm run seed:prismic`.

### Prismic setup

- **Locales**: add `fr-be` (French – Belgium) under Settings → Translations & locales.
- **Previews**: in Prismic → Settings → Previews, add `https://<your-domain>/api/preview`.
- **Publishing**: add a webhook on "document published" to `https://<your-domain>/api/revalidate`.
- **Types**: after changing models in Slice Machine, run `npm run types`.

## Design

Typography: Oswald (display), IBM Plex Sans (text), IBM Plex Mono (labels).
Palette: military slate and sand, with the green of the commando beret (`#224736`) as accent.
Colors and components are defined in `src/app/globals.css`. The line texture of the Fairbairn-Sykes
commando knife is generated by `npm run knife`.
